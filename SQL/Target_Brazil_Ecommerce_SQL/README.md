# Target Brazil E-Commerce SQL Analysis

## Project Overview

This project analyzes Target Brazil's e-commerce operations using SQL and Google BigQuery.

The dataset contains customer, order, payment, seller, and product information from 2016 to 2018.

## Business Problem

The objective is to understand customer behavior, order trends, delivery performance, and business growth using SQL queries.

## Key Insights

- Customer concentration is highest in major states.
- Order volume increased significantly from 2016 to 2018.
- Delivery performance varies across regions.
- Revenue showed strong growth over time.

## Business Recommendations

- Improve logistics in delayed regions.
- Focus marketing on high-performing states.
- Optimize seller performance tracking.
- Improve customer delivery experience.
